## Products

| | What it is | |
| --- | --- | --- |
| **[Localix Terminal](https://github.com/localixai/localix-terminal)** | The terminal for you and your coding agents. Terminal sessions that belong to a project and come back as you left them; Claude Code, Codex or any CLI agent runs in them. | [terminal.localix.ai](https://terminal.localix.ai) |
| **[Localix Studio](https://github.com/localixai/localix-studio)** | The Agentic Development Environment. An agent and its subagents work with you in one desktop app: your editor, terminals and browser, on any model. | [localix.ai](https://localix.ai) |
| **[Localix CLI](https://github.com/localixai/localix-cli)** | An ultrafast agent runtime for coding and CI, in Rust. `llx exec` runs one task and ends with an answer your pipeline can branch on. | [llx.sh](https://llx.sh) |
